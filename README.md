# claude-algo-coach

**让 AI 当教练，而不是当答案生成器。**

一个给 [Claude Code](https://claude.com/claude-code) 用的算法刷题教练 Skill。适用于洛谷、Codeforces、ICPC/CCPC 备赛、大学算法课作业——一切"给你一道题、你自己写代码"的场景。

> [English README](README.en.md)

> 💡 **不限于算法题**：这个 Skill 的内核是一套通用的「教练模式」——绝不代做、分级提示、复盘沉淀。把它用作**其他手写代码练习**的教练（语法练习、数据结构实现、课程项目……）同样适用：照同样的思路改掉「用户画像」和「讲义速查表」即可，四条铁律原样通用。

---

## 问题：让 AI 给你代码，你真的学会了吗？

大多数人用 AI 刷题的方式：

> "这题怎么做？" → AI 给出完整代码 → 看懂了 → 下一题。

结果是：**看得懂，写不出。**

算法能力来自"自己想出来 + 自己写出来"的过程。AI 一次性给出完整答案，恰恰把这个过程整个跳过了。

## 解法：把 AI 约束成教练

这个 Skill 用**四条铁律**把 AI 的行为锁死：

| 铁律 | 含义 |
|---|---|
| 🚫 **绝不直接给完整代码** | 哪怕你说"我不会""直接给我吧""就这一次" |
| 🤔 **不替你想** | 卡住时先反问"你觉得卡在哪一步？"，给方向、给自查方法，不给答案 |
| 📖 **每个问题定位到讲义** | "这个点在《07 讲》§7.7 讲过，回去看一眼"——复习有据可依 |
| 🔁 **每题通过后立刻复盘** | 双轨沉淀：本题小结写进题面文件，跨题通用坑进《易错点清单.md》 |

## 它是怎么带你的

### 阶段 1：新题开场 —— 只给框架，不给代码

你放好题面、说一句"开始做这题"。教练读题后输出：

1. **一句话题意**（人话翻译，不是抄题面）
2. **考点定位**（这题练什么）
3. **步骤拆解**（纯文字，不带任何代码）
4. **要点/坑**（用**提问方式**抛出："想想 n=0 时你的循环会怎样？"）
5. **建议自测数据**（让你自己想一组边界数据）

结尾固定一句：*"你先试着写，卡住了随时问我——把你想的思路说给我听。"*

### 阶段 2：卡住时 —— 四级分级提示（严格逐级，不许跳级）

| 级别 | 触发条件 | 教练给什么 |
|---|---|---|
| 1️⃣ 指方向 | 第一次说卡住 | 只说方向："问题在循环边界上，拿第 3 个样例手算一遍" |
| 2️⃣ 指位置 | 还卡 | 指出哪一行/哪个变量有问题，但**不说怎么改** |
| 3️⃣ 给伪代码 | 还卡 | 只给**那一步**的伪代码，不是整题 |
| 4️⃣ 给片段 | 实在写不出 | 给**那一小段**代码，讲清为什么 |

绝大多情况下，一两级提示就能让你自己接上——这正是你要的"想出来"的过程。

### 阶段 3：通过之后 —— 立刻详细复盘

代码逐段 review（写法 / 习惯 / 隐患：越界、溢出、未初始化、严格弱序……），每个问题**定位到讲义章节**；讲义没有的，明说"这是新知识，记一下"。

### 阶段 4：双轨沉淀

- **本题小结** → 1~3 行写进题面文件末尾（关键点 / 踩的坑 / 可复用的写法）
- **通用坑** → 进根目录的《易错点清单.md》（只记"下次换个题还会犯"的）
- 两条轨道分工明确，清单不会变成流水账

## 使用效果

作者用它带了三个场景：**洛谷刷题、Codeforces、大学的算法设计与分析课作业**。实际感受：

- **不再是"AI 写完我看一遍"**——全程自己动手，AI 只在卡壳处给最小提示
- **卡壳有梯度**——从"指个方向"到"给一小段代码"分四级，绝大多数时候浅层提示就够自己接上
- **复盘成体系**——每题的收获沉淀进题面文件，跨题通用坑攒成自己的"个人坑库"，越攒越少踩坑
- **讲义联动**——每个问题都能定位到教材章节，复习复习有据可依
- **迁移成本极低**——同一套规则从洛谷换到 CF、再换到课程作业，每次只改十来行（见 `examples/`）

## 安装（Claude Code）

在你的刷题项目根目录：

```bash
mkdir -p .claude/skills/algo-coach
curl -o .claude/skills/algo-coach/SKILL.md \
  https://raw.githubusercontent.com/DREAMERhyh/claude-algo-coach/main/SKILL.md
```

然后把本项目里的 `SKILL.md` 打开，按里面的说明**改掉两处和你相关的内容**：

1. **用户画像**——你现在的水平、目标（它决定教练怎么带你）
2. **讲义速查表**——你有自己的教材/讲义的话，把章节对应关系填进去（没有也能用）

最后从项目根目录打开 Claude Code 会话，就可以说"开始做这题"了。

> 💡 建议配合一个项目级 `CLAUDE.md` 说明用法（告诉会话"本项目用 algo-coach 模式工作"），效果更稳。`examples/` 里的三个适配版都含这种写法。

`examples/` 里是三个**可直接使用的完整版**——直接复制到 `.claude/skills/algo-coach/SKILL.md` 就能开工。

## 使用前提

- Claude Code（项目级 skill：`.claude/skills/<name>/SKILL.md`）
- （可选但强烈推荐）你自己的讲义 / 教材 / 课程笔记——铁律 3 靠它落地
- （可选）题面文件；没有的话教练也会先帮你把题目整理成文件
